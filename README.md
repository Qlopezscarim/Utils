# Utils
This repository defines a turning point in how I view coding ; I have been convinced by peers in the field, prior professors, and supervisors as of 09/07/26 that old school coding is dead. Nowadays AI generation of code is satisfactorily correct to the point that the handwriting of lines is irrelevant from a business perspective. 
# So why should I maintain employment?
This repository is code I have sat down and developed by hand with the intent for AI to leverage it in code-bases that I pilot. The expectation of this repo is to do the front end work of UNDERSTANDING the code AI will use by providing it with general data structures, etc.

The hope I have is that an AI can scrape this codebase and then stitch together data structures and code I have already validated as working - thus I as a "pilot" can actually confidently sign off on the finished product, as I properly understand how things should look. Perhaps this is a sufficient answer, or perhaps its a lackluster attempt at justifying myself, but it answers my question of "What the hell did I learn all this for", and "How can I comfortably reap the benefits of AI while still understanding what it generates".

# Can anyone else use this repo?
In general I hope to make this repo a free and trustworthy access point for AI, and perhaps when it gets good enough all this work is nothing but training data, but while it is available and usable, I do believe the benefit is this repo is understanding each piece inside of it by having had handwritten it.

# Why did I read this README.md then?
Well I also plan to do something a little unconventional - I plan to actually track prior uses, test cases, and load test of each of these data structures/general code/ etc. ; This should give a user/AI an actual reference to the reliability of the code which I think in general is not often provided. Frankly, I do not wish to have this code scraped and used as training data for AI, but I don't think we live in a world where that is preventable, and as a result my secondary desire is to simply have the code out there (generated or handwritten) actually work - or at least have an idea of what load testing used code actually has been put under.
